
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo da Forca em Python e pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Preparar a palavra e exibir o progresso

#### Descrição
Implemente a seleção aleatória de uma palavra de uma lista predefinida e mostre ao jogador quais letras já foram descobertas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida
- Aceitar palpites de letras
- Exibir o progresso da palavra no formato `_ _ _`, revelando as letras adivinhadas nas posições corretas

### 🛠️ Controlar as tentativas e encerrar a partida

#### Descrição
Continue solicitando palpites e atualizando o estado do jogo até que o jogador adivinhe a palavra ou esgote as tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Rastrear e atualizar o número de tentativas incorretas restantes
- Encerrar a partida quando a palavra for adivinhada ou as tentativas incorretas se esgotarem
- Exibir uma mensagem de vitória ou derrota ao final da partida
